# ニチゲツ会社

このリポジトリはニチゲツ会社のプロジェクト管理リポジトリです。

## 概要

ニチゲツ会社のソースコード・ドキュメント・設定ファイルを管理します。

## 開発環境のセットアップ

```bash
# リポジトリをクローン
git clone https://github.com/like0the0wind-ai/nichigetu-kaisha.git
cd nichigetu-kaisha
```

## コントリビュート

1. ブランチを作成する (`git checkout -b feature/your-feature`)
2. 変更をコミットする (`git commit -m 'Add some feature'`)
3. ブランチをプッシュする (`git push origin feature/your-feature`)
4. Pull Request を作成する
