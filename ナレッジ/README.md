# ナレッジ

パン屋ニチゲツのオーナーが蓄積する知識・考え・情報を保管するフォルダです。

## フォルダ構成

| フォルダ | 用途 |
|---|---|
| `オーナー日記・アイデア/` | 日々の気づき、経営アイデア、将来の構想メモ |
| `業界情報/` | トレンド、仕入れ情報、競合調査、セミナーメモ |
| `チームへの共有事項/` | スタッフへの連絡事項、ミーティングメモ、マニュアル |

## 使い方

- 日付をファイル名に含めると管理しやすいです（例: `20240601_アイデアメモ.md`）
- 「書いたけど忘れた」をなくすことが目的です。完璧でなくて OK。
