# PR業務

パン屋ニチゲツの広報・集客に関する素材・記録を管理するフォルダです。

## フォルダ構成

| フォルダ | 用途 |
|---|---|
| `SNS投稿・素材/Instagram/` | Instagram 用の画像・動画・投稿文テキスト |
| `SNS投稿・素材/X（Twitter）/` | X（旧Twitter）用の投稿テキスト・素材 |
| `チラシ・メニュー/` | 印刷用チラシ、メニュー表のデータ |
| `お客様の声/` | 口コミ・アンケート・フィードバックの記録 |
| `イベント・キャンペーン/` | 季節企画・特売・コラボ企画の計画・記録 |

## 運用ルール（例）

- SNS投稿は投稿後にファイルを保存（素材の使い回しができるように）
- お客様の声は月1回まとめて記録し、改善提案シートに反映する
